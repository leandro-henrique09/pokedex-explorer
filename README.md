# 🎮 Pokédex Explorer

Uma aplicação web desenvolvida com **HTML, CSS e TypeScript** que consome a [PokéAPI](https://pokeapi.co/) para explorar informações sobre o universo Pokémon.

O projeto tem como objetivo praticar o consumo de APIs REST, tipagem com TypeScript, programação assíncrona e manipulação do DOM, construindo uma aplicação interativa passo a passo.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e layout responsivo.
- **TypeScript** — tipagem estática e organização do código.
- **Vite** — ambiente de desenvolvimento e build.
- **PokéAPI** — API REST utilizada para obter os dados dos Pokémon.

## ✨ Funcionalidades

- [x] Consultar Pokémon através da PokéAPI.
- [x] Exibir uma lista inicial com 10 Pokémon.
- [x] Buscar informações individuais de cada Pokémon.
- [x] Utilizar interfaces TypeScript para representar os dados recebidos.
- [x] Implementar tratamento básico de erros nas requisições.
- [ ] Exibir cards com imagens, números e tipos dos Pokémon.
- [ ] Desenvolver uma interface visual personalizada.
- [ ] Adicionar novas funcionalidades de exploração.

## 🛠️ Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm, instalado junto com o Node.js.

### Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/leandro-henrique09/pokedex-explorer
   ```

2. Entre na pasta do projeto:

   ```bash
   cd pokedex-explorer
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra no navegador o endereço exibido no terminal.

## 📚 Aprendizados

Durante o desenvolvimento, estou praticando:

- Requisições HTTP com `fetch()`.
- Programação assíncrona com `async/await`.
- Tratamento de erros com `try/catch` e `throw new Error()`.
- Interfaces e tipagem de objetos com TypeScript.
- Manipulação do DOM com métodos como `querySelector()`, `createElement()` e `appendChild()`.
- Organização de funções e separação de responsabilidades.
- Consumo e interpretação de dados JSON.
